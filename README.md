# 蓬蒿人 - 个人主页

一个现代化的 GitHub 个人主页，展示开发者的技术能力、项目成果和联系方式。

## 技术栈

- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **图标**: Font Awesome 6.4.0
- **托管**: GitHub Pages

## 功能特性

- 🎨 **深色科技主题**: 采用深蓝色调，搭配青色点缀
- ✨ **动态效果**: Hero 区域动态背景、打字机文字效果
- 📱 **响应式设计**: 完美适配桌面端、平板和移动端
- 🎯 **平滑滚动**: 导航栏平滑滚动到各模块
- 🚀 **入场动画**: 滚动时元素渐入动画效果
- 📧 **联系表单**: 支持在线留言功能

## 页面结构

```
├── 导航栏 (固定顶部)
├── Hero 区域 (个人头像、姓名、职业标签)
├── 关于我 (个人简介、座右铭、统计数据)
├── 技术栈 (8 项技能展示，带进度条)
├── 我的项目 (4 个项目卡片展示)
├── 联系方式 (社交链接、联系表单)
└── 页脚 (版权信息)
```

## 开发

```bash
# 克隆项目
git clone https://github.com/z546948105/z546948105.github.io.git

# 进入项目目录
cd z546948105.github.io

# 启动本地服务器
python -m http.server 8080
```

然后打开浏览器访问 `http://localhost:8080`

## 部署到 GitHub Pages

1. 确保所有更改已提交到 `main` 分支
2. 打开 GitHub 仓库页面
3. 进入 **Settings** → **Pages**
4. 在 **Source** 部分选择 `main` 分支和 `/ (root)`
5. 点击 **Save**
6. 等待几分钟后，访问 `https://z546948105.github.io`

## 自定义内容

编辑以下文件来自定义个人信息：

- `index.html`: 修改姓名、职业、项目、联系方式等
- `css/style.css`: 修改主题色、字体、布局等
- `js/main.js`: 修改打字机文本、动画效果等
- `images/avatar.jpg`: 替换为个人头像
